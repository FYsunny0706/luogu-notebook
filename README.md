# 洛谷刷题本 · Luogu Notebook

本地运行的刷题记录工具：**文件夹树整理题目、同步洛谷账号进度、C++ 本地评测、一键导出成 PDF 文件**。
零依赖、纯本地、数据存自己硬盘，解压即用，也可以打包发给别人。

> 当前版本 **v1.0.0**

---

## 快速开始

**Windows**：双击 `start.bat`
**macOS / Linux**：终端里 `./start.sh`（首次可能需要 `chmod +x start.sh`）

浏览器会自动打开 <http://127.0.0.1:8765/>，关掉那个黑窗口/终端就停止服务。

第一次启动会弹出**环境向导**，自动体检编译器、PDF 浏览器、代码格式化工具，缺什么点一下就能配。

> 需要 **Node.js 20+**（[下载](https://nodejs.org/)）。前端依赖已经内置在 `public/vendor/`，**断网也能用**。

## 界面怎么用

```
┌──────────────┬───────────────────────┬──────────────────────────────┐
│ 索引（文件夹树）│   题目                │   我的代码 · C++17            │
│ 📁 可任意嵌套  │  题号·难度·算法标签     │  编辑器 + 运行/测试点          │
│ 📁 拖拽整理    │  输入输出格式/样例      │  输入(stdin) / 期望输出        │
│   多选/框选    │  情景自动折叠省版面     │  运行结果（错误可点击跳转）     │
└──────────────┴───────────────────────┴──────────────────────────────┘
```

1. **加题**：顶部输入**题号**（`P1001`、`CF1A`）或**题名**（`采药`、`树状数组`），从候选里挑一个回车添加。
2. **整理**：`+ 文件夹` / `+ 子文件夹` 建可任意嵌套的文件夹；拖动调整位置——拖到行的上/下边缘是排序，拖到文件夹**中间**是放进去。
3. **批量**：在空白处**按住鼠标框选**，或 `Ctrl` / `Shift` 点选；底部会出现操作条，可批量删除、移动到文件夹、改状态。
   **删除不弹确认框**，误删了按 `Ctrl+Z` 或点提示里的「撤销」。
4. **写代码**：右边高亮编辑器，支持 Tab 缩进、括号配对；`格式化` 按钮调用 clang-format。
5. **测试**：
   - `▶ 运行`（`Ctrl+Enter`）跑你填的输入
   - `评测样例` 用洛谷样例逐点比对，全过自动标成「已通过」
   - **测试点**页签：把数据存成多组自测点，一键全测，每个点单独显示 AC/WA
6. **同步洛谷**：点「同步洛谷」填 **UID**（不用密码），拉取账号里已通过的题目，可一键对齐状态或批量导入（先导轻量条目，打开时自动补全题面，100+ 题也是秒进）。
7. **导出 PDF**：右上角「导出 PDF」→ 选范围/配色/版式 → **直接生成文件**到 `exports/` 并自动下载，不弹浏览器打印窗口。
8. **分享单题**：`导出 → 导出当前题目为分享卡片`，得到一个小 `.json`，别人 `导入分享卡片` 就能收到题面+代码+笔记+测试点。

## 功能清单

| 分类 | 功能 |
| --- | --- |
| 抓题 | 按题号或题名搜索、自动抓标题/难度/算法标签/输入输出格式/样例/时限内存/通过率 |
| 题面 | 自动剥离广告与无关段落；**情景故事自动折叠**（导出 PDF 时会补回原文，避免看不懂题）；KaTeX 公式渲染 |
| 索引 | 任意层级文件夹树、拖拽排序与拖入、折叠、文件夹级笔记、多选/框选、批量删除与移动 |
| 编辑 | C++17 语法高亮、行号、Tab 缩进、括号配对、clang-format 格式化、编译错误点击跳转 |
| 评测 | 本地 g++ 编译运行、`AC/WA/TLE/RE/CE` 判定、超时自动杀进程、多组自测数据点一键全测 |
| 进度 | 洛谷 UID 同步已通过题目、状态标记（未做/已通过/待复习/卡住）、学习统计图表 |
| 检索 | 全文搜索（题号/题名/标签/代码/笔记）+ 状态/难度/标签多维筛选 |
| 数据 | 每次保存自动导出 `notebook.md`、Markdown 双向导入、JSON 备份、单题分享卡片、**多刷题本档案** |
| 导出 | PDF（5 套配色、题目代码左右分栏、每道题不跨页）、Markdown、JSON |

## PDF 配色模板

| 模板 | 风格 |
| --- | --- |
| 简约黑白 | 白底黑字细边框，最通用、最省墨 |
| 护眼米黄 | 米黄背景，长时间看不累 |
| 深色模式 | 整页深色底 + 浅色文字，代码语法高亮同步适配 |
| 蓝调商务 | 蓝灰主色 + 色块标题，适合归档成册 |
| 高对比大字 | 字号放大、行宽拉高，适合平板阅读 |

PDF 由**系统自带的 Edge/Chrome 无头模式**渲染，中文、公式、代码高亮都是矢量的，文字可选中可搜索。
导出时会给每道题**自动压缩到一页**：先按 A4 正文宽度量一遍高度，超出可用页高就按比例缩放（最少缩到 55%），
所以「高对比大字」也不会因为字号变大就多占几页。

界面本身也有三套配色：**深色 / 浅色 / 琥珀**，右上角切换，选择会记住。

界面语言支持 **简体中文 / 繁體中文 / English**，右上角下拉切换，同样会记住。
文案统一放在 `locales/*.json`，改完跑 `node tools/build-i18n.mjs` 生成 `public/locales.js` 生效；
那个脚本会顺便校验三种语言的键是否一致、有没有漏翻。

## 文件结构

```
luogu-notebook/
├─ start.bat / start.sh   启动脚本（Windows / macOS·Linux）
├─ server.mjs             后端服务（零依赖，只用 Node 内置模块）
├─ config.json            环境配置（首次启动自动生成）
├─ lib/
│  ├─ luogu.mjs           抓题：cookie jar、题面解析、情景分离、练习数据
│  ├─ judge.mjs           C++ 编译运行、超时强杀
│  ├─ format.mjs          clang-format 接入与下载
│  ├─ store.mjs           存档：文件夹树 ↔ Markdown、多档案、分享卡片
│  └─ pdf.mjs             PDF：打印 HTML + 配色模板 + 无头渲染
├─ public/                前端界面（app.js / style.css / vendor 离线依赖）
├─ data/                  ★ 你的数据都在这里
│  ├─ profiles.json       档案列表
│  ├─ notebooks/<档案>.json  结构化数据（唯一数据源）
│  ├─ notebooks/<档案>.md    自动导出的 Markdown
│  └─ backups/            手动备份
├─ exports/               导出的 PDF
├─ build/                 编译产物与临时文件，可随时整个删掉
└─ tools/                 自测脚本、打包脚本
```

## 分发给别人

```bash
node tools/package.mjs        # 等价于 npm run package
```

会在 `dist/` 生成 `luogu-notebook-v1.0.0.zip`（约 1.7 MB，93 个文件），**自动排除** `data/`、`config.json`、`exports/`、`build/` 等个人数据。
对方解压后双击 `start.bat` 即可，首次启动会有向导带着配环境。

## 环境依赖

| 用途 | 依赖 | 缺失时 |
| --- | --- | --- |
| 运行 | Node.js 20+ | 启动脚本会提示去官网装 |
| 编译评测 | g++（MinGW-w64 / MSYS2 / RedPanda-CPP 自带的都行） | 只能看题不能跑代码；向导里有入口手动指定路径 |
| 导出 PDF | Edge 或 Chrome | PDF 导出不可用；其余功能正常 |
| 代码格式化 | clang-format（可选） | 「格式化」按钮会提示下载地址 |

本机当前用的是小熊猫 RedPanda 自带的 MinGW：`D:\royqh\mingw64\bin\g++.exe`
（编译/运行时会自动把它的 `bin` 加进 PATH，否则 `cc1plus` 会因缺 DLL 静默失败）。

## 常见问题

- **抓题失败 / 人机验证**：洛谷有反爬，隔几秒重试。
- **同步报「隐私」**：对方把练习数据设为私密了；自己的账号在洛谷「设置 → 隐私」里开放即可。
- **运行报 `0xC0000135`**：编译器路径不对或 DLL 找不到 → ⚙ 里确认 `g++.exe` 路径。
- **导出 PDF 报「浏览器无法创建内部通信管道」**：说明服务跑在受限沙箱里，用 `start.bat` 正常启动即可。
- **第一次运行编译出来的程序特别慢**：Windows 首次执行新 exe 会被杀软扫描，第二次就快了；服务启动时已预热。
- **程序卡死没输出**：点 `■ 停止`；评测本身有超时保护，不会留下死循环进程。
- **端口被占用**：会自动从 8765 往后找，看窗口里打印的实际地址。
- **误删了东西**：`Ctrl+Z` 撤销（删除、移动、批量改状态都可撤销，最多 40 步）。

## 开发自测

```bash
node tools/build-i18n.mjs       # 由 locales/*.json 生成 public/locales.js，并校验三语键一致
node tools/test-roundtrip.mjs   # 文件夹树 ↔ Markdown 往返无损 + 旧数据迁移 + 测试点
node tools/test-narrative.mjs   # 情景分离启发式检查
node tools/test-caret.mjs       # 编辑器光标对齐：高亮层与输入层字体必须逐像素一致
node tools/test-i18n.mjs        # 多语言：键一致性 + 实际切换 + 英文界面无漏翻中文（13 项）
node tools/ui-test.mjs          # 无头浏览器端到端：树/框选/撤销/测试点/档案/分享/PDF
node tools/test-uipdf.mjs       # 编辑器长代码滚动 / 三套界面配色 / PDF 一题一页 / 背景无白边（20 项）
node tools/test-pdf.mjs         # PDF 生成、5 套配色、栏目标签跟随语言
node tools/test-print-css.mjs   # 打印页几何自检：@page 零边距、页边距由内边距提供、压缩只看内容层
node tools/verify-pdf-bg.mjs    # 直接渲染 PDF 并逐页检查背景有没有白边（需要能启动浏览器）
node tools/check-pdf-bg.mjs     # 检查某个已有 PDF 的背景有没有白边
node tools/preview-print.mjs    # 把 PDF 排版渲染成图片做视觉验收
node tools/seed-demo.mjs        # 灌入演示数据

node tools/package.mjs          # 打包分发 zip
```

## 说明

- 洛谷的**官方测试数据不公开**（记录页需要登录、没有 testdata 接口），所以本工具不提供代提交功能，
  而是用「洛谷样例 + 多组自测数据点」来覆盖本地验证需求。
- 洛谷账号同步只读取**公开的练习数据**，不需要密码、不存任何凭据。
- 本工具与洛谷官方无关，请遵守洛谷的用户协议，不要用它做自动化提交或抓取。
