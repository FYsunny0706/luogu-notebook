# 换行符规范：批处理必须 CRLF，Shell 必须 LF，否则会让对方解压后运行报错
* text=auto eol=lf

*.bat text eol=crlf
*.cmd text eol=crlf
*.ps1 text eol=crlf

*.sh text eol=lf
*.bash text eol=lf

# 二进制文件不要动
*.png binary
*.jpg binary
*.jpeg binary
*.gif binary
*.ico binary
*.woff binary
*.woff2 binary
*.ttf binary
*.pdf binary
*.zip binary
